An image that hardcodes its database URL has to be rebuilt per environment.
A <Term>ConfigMap</Term> pulls that data out of the image and into the cluster.

For sensitive values there is <Term term="Secret">Secrets</Term>, which look
similar but are handled with more care. Worth being blunt early: base64 is not
encryption.

Either can be injected as environment variables or mounted as a
<Term>volume</Term>.
