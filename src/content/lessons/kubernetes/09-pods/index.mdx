A <Term>node</Term> is a single machine in the cluster. On it runs a
<Term>kubelet</Term>, the agent responsible for actually starting work.

The unit of work is the <Term>pod</Term>: one or more
<Term term="Container">containers</Term> that share a network namespace and
storage. Containers inside a pod reach each other over localhost.

Deciding which node a pod lands on is the <Term>scheduler</Term>'s job. It
filters out nodes that cannot fit the pod, then ranks what is left.
